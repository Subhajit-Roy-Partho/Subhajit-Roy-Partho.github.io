## Basic installation

Install the packages:

```bash
sudo apt install -y munge libmunge-dev
```

Create munge keys:

```bash
sudo /usr/sbin/create-munge-key
sudo chown munge: /etc/munge/munge.key
sudo chmod 400 /etc/munge/munge.key
```

If the above fails, do it manually with:

```bash
sudo mungekey --create --force --keyfile /etc/munge/munge.key
sudo chown -R munge: /etc/munge /var/log/munge /var/lib/munge /run/munge
sudo chmod 0700 /etc/munge /var/log/munge /var/lib/munge
sudo chmod 0755 /run/munge
```

Start and check munge:

```bash
sudo systemctl enable munge
sudo systemctl start munge
sudo systemctl status munge
munge -n | unmunge
```

Result should look like:


  Installing SLURM on WSL Ubuntu with `sudo apt install -y slurm-wlm` is the easy path, but it's an older build with
  partial GPU feature support that often fails — compile from source for the advanced features.
</Callout>

## Everyday commands

- Show fairshare usage for various queues/partitions: `sacctmgr show qos`
- Show a user's fairshare score: `sshare -l | grep usernameOrGrpName`
- Basic partition info: `sinfo -p sulcgpu3 -o "%P %a %l %D %t %N"` or `sinfo -Nel | grep "sulcgpu3"`
- Info on a particular node: `scontrol show node nodeName`
- Queue info: `squeue -p partitionName` or `squeue -u userName`
- Submit an empty job: `sbatch -n 20 --gres=gpu:1 --time=4:00:00 -q sulcgpu1 -p sulcgpu1 --output=/dev/null --error=/dev/null $@ _interactiveScript`

where `_interactiveScript` can be as simple as:

```bash
#!/bin/sh
# Simple batch script that starts SCREEN.
exec screen -Dm -S slurm$SLURM_JOB_ID
```

Empty jobs can also be submitted as a SLURM script:

```bash
#!/bin/sh
#SBATCH -q private
#SBATCH -p general
#SBATCH -G a100:1
#SBATCH -t 5-00:00
#SBATCH -c 20
#SBATCH -o empty.out
#SBATCH -e empty.err
#SBATCH -J PHBdnaD

exec screen -Dm -S slurm$SLURM_JOB_ID
```

To enter a submitted job, use `srun --pty --jobid=######## /bin/bash` or simply `ssh nodeid`.

## Setting up slurmdbd

Install MariaDB:

```bash
sudo apt-get install mariadb-server
sudo systemctl enable mariadb
sudo systemctl start mariadb
```

Create a database for SLURM:

```sql
sudo mysql -u root -p
CREATE DATABASE slurm_acct_db;
CREATE USER 'slurmuser'@'localhost' IDENTIFIED BY 'slurmPass';
GRANT ALL ON slurm_acct_db.* TO 'slurmuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

The default MariaDB port is 3306 — confirm with `sudo ss -tulpn`. Adjust these in `/etc/mysql/mariadb.conf.d/50-server.cnf`:

```ini
innodb_buffer_pool_size = 1G
innodb_lock_wait_timeout = 300
```

```bash
sudo systemctl restart mariadb; sudo systemctl status mariadb
```

Register the account and user:

```bash
sudo sacctmgr add account generic cluster=ringtail description="Generic Account" organization="SulcLab"
sacctmgr list account
sudo sacctmgr add user subho account=generic cluster=ringtail
```

Sharing Mouse & Keyboard with Barrier

Generating a self-signed SSL cert for Barrier so one keyboard and mouse can control multiple machines.

#linux#networking#productivity

Barrier lets one keyboard and mouse control several computers over the network.

  1. Install it via your package manager, or build it from the GitHub repo.
  2. Generate a self-signed SSL certificate at .local/share/barrier/SSL (either under /home/$USER or /home/$USER/snap/barrier-*/2):
  1. On the server, configure the screen layout by dragging the new PC to the left or right of the current one, then start the server.
  2. On the client, connect using the server's IP. If everything's set up correctly, the client will show the server's SSL fingerprint and prompt that the configuration is ready.

Vim Commands & Neovim C++ Setup

Search-and-replace patterns worth memorizing, plus wiring up NvChad with Mason and clangd for C++ development.

#vim#neovim#editor

Useful vim commands

Search and replace

  • :s/search/replace/ — current line, first occurrence.
  • :s/search/replace/g — current line, all occurrences.
  • :%s/search/replace/g — entire file.
  • :3,10s/search/replace/g — lines 3 through 10.
  • :.,+4s/search/replace/g — current line through the next 4 lines.
  • :.,$s/search/replace/ — current line to end of file.
  • Append gc to confirm each substitution individually.
  • Append gi to ignore case.

Folding

:set foldmethod=indent folds lines by indentation.

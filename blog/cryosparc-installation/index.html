CryoSPARC Installation & Management

Licensing, installing, and standing up a CryoSPARC master on a single machine or an HPC cluster node.

#cryo-em#hpc#linux

Installation

  1. Request a license — it usually takes CryoSPARC about two business days to issue one.
  2. Add it to your shell profile: export LICENSE_ID="<license_id>" in .bashrc.
  3. Download the master (and, for a cluster, the worker) package:

For a single-PC setup, only the master package is required.

  1. Extract it:

Install as a non-root user — run the install.sh steps below from a regular account, not as root.

  1. Pick a database location — scratch space works well on a cluster, e.g. /scratch/cryo/cryoDB.
  2. Install from the extracted folder:

Single workstation: add --standalone with --worker_path /path/to/cryosparc_worker so the install bundles the worker setup in the same run.

Get the hostname with hostname. On a cluster this changes with node allocation, so update config.sh accordingly — adding export CRYOSPARC_FORCE_HOSTNAME=true to config.sh also helps.

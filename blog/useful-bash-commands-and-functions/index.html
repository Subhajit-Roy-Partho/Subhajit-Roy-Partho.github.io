Server shortcut function

Replace server with whatever name you like, user with your username, and serverIP with the server's address.

  • server — just logs you in.
  • server send yourLocation serverLocation — sends a file to the server.
  • server receive serverLocation yourLocation — downloads a file from the server.
  • server "command" — runs a command remotely, e.g. server myjobs, server "cat file", server "tail file".
